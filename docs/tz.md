# Техническое задание (ГОСТ 19.201-78)

**Программа:** «Сумма столбцов с нулевым элементом» («МатрСум»), шифр темы «МатрСум-11».

## 1. Введение
Программа находит сумму элементов тех столбцов вещественной матрицы,
которые содержат хотя бы один нулевой элемент.

## 2. Основания для разработки
Лабораторная работа №1 по дисциплине «Инструментальные средства разработки
программного обеспечения», специальность 09.02.07
«Информационные системы и программирование».

## 3. Назначение разработки
- ввод размерности матрицы (n строк, m столбцов);
- ввод элементов матрицы (вещественные числа) построчно;
- проверка корректности ввода;
- поиск столбцов, содержащих хотя бы один нулевой элемент;
- вычисление общей суммы элементов найденных столбцов;
- вывод номеров столбцов и итоговой суммы.

## 4. Требования к программе
- n ≥ 1, m ≥ 1 — натуральные числа; элементы — вещественные числа;
- при некорректном вводе — повторный запрос;
- если столбцов с нулём нет — сообщение об этом и сумма 0;
- результат выводится с точностью 3 знака после запятой;
- возможность повторного запуска без перезагрузки;
- платформа: Windows 7/10/11 или Linux, Python 3.x.

## 5. Структура программы
- `input_matrix()` — ввод размерности и элементов матрицы;
- `find_zero_columns_sum(matrix)` — поиск столбцов с нулём и суммирование;
- `print_results(columns, total_sum)` — вывод результата;
- `main()` — управление и цикл «продолжить?».
